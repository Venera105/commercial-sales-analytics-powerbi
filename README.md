# Анализ коммерческих продаж и маржинальности бизнеса в Power BI 📊

Многостраничный интерактивный дашборд для анализа эффективности продаж, расчета себестоимости и оценки чистой прибыли компании с учетом статусов заказов (отмены и возвраты).

## 🎯 Бизнес-цель проекта
Понять, какие категории товаров приносят компании наибольшую маржинальность, выявить топ-продукты, проанализировать динамику продаж во времени и оценить финансовые потери от отмен и возвратов.

## 🛠️ Используемый стек и технологии
* **Power BI Desktop** (проектирование дашборда, визуализация)
* **DAX** (расчет бизнес-метрик)
* **Моделирование данных:** связывание таблиц фактов (`public_sales`, `public_orders`) со справочниками (`nomenclature_reference`, `public_order_status`).

## 📈 Структура отчета и ключевые метрики

### Страница 1: «Продажи и прибыль»
На этой странице реализован верхнеуровневый аудит коммерческих показателей. 

**Ключевые KPI (Calculated Measures на DAX):**
* **Total Sales (Общая выручка):** Агрегированная сумма фактических продаж.
* **Cost (Себестоимость):** Рассчитана на основе цен закупки из справочника цен, умноженных на объем проданного товара.
* **Profit (Прибыль):** Чистая разница между выручкой и себестоимостью ($Sales - Cost$).
* **Profit Margin % (Рентабельность):** Доля прибыли в общей выручке.

**Визуализации:**
1. **Динамика продаж (Line/Bar chart):** Временной ряд, отражающий тренды и сезонность продаж по дням/месяцам.
2. **Топ-5 категорий по прибыли:** Выявление наиболее маржинальных товарных групп из справочника номенклатуры.
3. **Управленческий фильтр (Slicer):** Интерактивная фильтрация по статусам заказов (Доставлено, В пути, Отменено, Возврат) для моментальной переоценки упущенной выгоды.
